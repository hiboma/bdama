# ADR-0005: 積み木モードの追加（下書き）

## ステータス

下書き (2026-03-14)

## コンテキスト

ビー玉ころころは現在「おえかきモード」のみで遊べます。指で線を描いて棚を作りビー玉を導くモードです。新たに「積み木モード」を追加し、ゲームの遊び方のバリエーションを増やします。

### おえかきモードとの違い

| 項目 | おえかきモード | 積み木モード |
|------|--------------|-------------|
| 操作 | 線を描いて棚を作る | 配置済み棚パーツをD&Dで移動・回転 |
| パーツ生成 | プレイヤーが描画 | ランダム配置で自動生成 |
| 障害物操作 | 不可 | 通常は不可。「じゆう」モードで可能 |
| 背景色 | クリーム色 + 赤ストライプ | 淡い青 + ゴールドストライプ |
| フェーズ | 描画 → 転がし | 配置 → 転がし（転がし中も移動可） |
| 制限時間 | 30秒 | 60秒 |
| スコア | ゴール数 + ボーナス | ゴール数 + 未使用パーツ数 + 時間ボーナス |

## 決定事項

### 1. ゲームデザイン

積み木モードでは、ステージ開始時にランダム配置されたパーツ（棚・障害物）が登場します。棚パーツをドラッグ&ドロップで移動・回転して、ビー玉をゴールに導きます。障害物は通常移動できません。

### 2. パーツの種類

- **棚（板）パーツ**: 3〜4本。長さ（104/156/208px）と角度はランダムで生成します。木目模様の描画を施します。
- **障害物パーツ**: レベルに応じて3〜5個。既存の4種（しかく・まる・さんかく・くるくる）を使います。

### 3. 操作方法

- **移動**: 棚パーツをタッチしてドラッグで移動します。
- **回転**: パーツをタップすると回転ハンドル（丸いつまみ + 破線）が表示され、ハンドルをドラッグして回転します。
- **実行中操作**: ビー玉転がし中も棚パーツを動かせます。
- **じゆうモード**: タイトル画面のトグルで有効化すると、障害物パーツも移動・回転可能になります。

### 4. 配置の制約

- パーツ同士の重なりは許可します。
- 画面外へのはみ出しは防止します（マージン20px）。
- スタート・ゴール位置にパーツを重ねることは禁止します（保護半径45px）。

### 5. フェーズ設計

2フェーズ制を採用します。

1. **配置フェーズ**: 物理演算停止。パーツを自由に配置します。
2. **実行フェーズ**: スタート地点のビー玉タップで遷移します。物理演算開始。棚パーツの移動も引き続き可能です。

フェーズ切り替え時に「スタート！」テキストと画面フラッシュのフィードバックUIを表示します。

### 6. 解けないステージへの対処

リセットボタンで障害物を再生成します。現在のモードと同じ操作感を維持します。

### 7. スコアリング

基本のゴールスコアに加えて、積み木モード独自の得点要素を追加します。

- **未移動パーツボーナス**: 動かさなかったパーツ数を加算します
- **時間ボーナス**: 残り秒数 / 5 を加算します
- **スター判定**: 2点 / 5点 / 8点

### 8. ビジュアル

- 背景色を淡い青（#E8F0FE）+ ゴールドストライプに変更し、おえかきモードと視覚的に区別します。
- サーカスランドのテーマは維持します。
- 棚パーツは木目模様のグラデーション描画を施します。
- 選択中のパーツには回転対応の青い破線枠を表示します。
- ヒットエリアは各パーツの形状に合わせます（回転考慮）。

### 9. モード選択UI

タイトル画面に「おえかき」と「つみき」の2つのトグルボタンを追加します。積み木モード選択時には「じゆう」トグルスイッチが追加で表示されます。

### 10. 制限時間

積み木モードの制限時間は60秒です（おえかきモードは30秒）。

## 影響

- `Game.ts` に `GameMode` 型とモード分岐ロジックを追加します。積み木パーツの生成・D&D・回転・ヒットテスト・スコア計算を実装します。
- `Renderer.ts` に積み木モード用の背景・棚パーツ描画・回転ハンドル・選択ハイライト・フェーズ切り替えアニメーション・クリア画面・トグルUI を追加します。
- タイトル画面のレイアウトを調整します。
